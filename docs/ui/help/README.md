# Пользовательская справка Bee Search (v2)

`help-v2.md` — канонический источник встроенной справки. Встроенная справка
генерируется из него, поэтому текст правится только здесь.

## Что где лежит

```text
docs/ui/help/help-v2.md                     канонический текст (source of truth)
docs/ui/help/img/                           изображения для справки (пока пусто)
docs/ui/help/README.md                      этот файл
app/src/main/java/.../ui/help/HelpContent.kt  GENERATED — править нельзя
app/src/main/java/.../ui/help/HelpScreen.kt   отображение справки в приложении
app/src/test/java/.../ui/help/HelpMarkdownParser.kt  разбор разметки (только тесты)
```

`HelpContent.kt` помечен как сгенерированный. Любая правка текста делается в
`help-v2.md`; после неё содержимое пересобирается генератором.

## Как пересобрать встроенную справку

Windows (PowerShell):

```powershell
$env:HELP_REGENERATE="1"; .\gradlew.bat :app:testDebugUnitTest --tests "*HelpContentGenerationTest*"
```

Затем уберите переменную окружения. Проверка рассинхронизации — обычный запуск
тестов без переменной:

```powershell
.\gradlew.bat :app:testDebugUnitTest --tests "*HelpContentGenerationTest*"
```

Тест сравнивает то, что разбирается из `help-v2.md`, с тем, что лежит в
`HelpContent.kt`, и падает, если они разошлись. Отдельного шага сборки,
скрипта и внешних инструментов для этого не требуется.

## Разметка

Поддерживается небольшое подмножество Markdown. Всё, что стоит до первого
заголовка `## `, считается служебной шапкой документа и в приложение не
попадает.

| Разметка | Значение |
|---|---|
| `## Название` | раздел справки (уровень 1) |
| `### Название` | подраздел (уровень 2), показывается как часть предыдущего раздела |
| пустая строка между блоками | граница абзаца |
| подряд идущие строки текста | один абзац |
| `1. текст` | шаг нумерованного списка |
| `- текст` | пункт списка |
| `> текст` | подсказка (выделенный блок) |
| `![подпись](help_slot_name)` | место для изображения: имя ресурса и его описание для доступности |
| `%EXCHANGE_PATH%` | подстановка пути к папке обмена текущей сборки |
| ` ```text ... ``` ` | блок с сохранением переносов строк (моноширинный) |
| `---` | разделитель для чтения исходника, в приложение не попадает |

Первый раздел `## Краткий старт` показывается отдельным блоком «Краткий старт»
в начале экрана. Остальные разделы идут в том порядке, в котором записаны.

Внутри абзацев не используется разметка `**жирный**` и обратные кавычки: экран
справки показывает обычный текст, поэтому такие символы были бы видны как есть.

## Изображения

Разметка мест для изображений уже есть, сами изображения добавляются позже и
отдельно. Пока файла ресурса нет, приложение ничего не показывает и не
оставляет пустого места. Когда изображение появится, его нужно положить в
`app/src/main/res/drawable-nodpi/help/` под тем именем, которое указано в
`help-v2.md` (например `help_map_main.png`), и пересобрать справку (генерация
не нужна: имя ресурса уже в тексте).

Придуманные или устаревшие снимки экрана в справку не добавляются: справка
должна показывать текущий интерфейс.
