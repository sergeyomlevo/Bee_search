# Удаление сохранённого GPX — дополнение к display v1

**APPROVED BY OWNER, 2026-10-19.**
Общий сценарий long press → Удалить → подтверждение уже утверждён OWNER.
[Базовый утверждённый макет](gpx-display-v1.md) и его композиция сохраняются.
[PNG](gpx-display-delete-v1.png); [HTML](gpx-display-delete-v1.html) — воспроизводимый источник статического
макета с увеличенным в1.7 раза текстом, не runtime/device evidence.

- Обычный tap строки по-прежнему меняет видимость.
- Long press имени открывает одно контекстное действие `Удалить`.
- Для accessibility: custom action `Удалить трек` открывает то же подтверждение,
  никогда не выполняет удаление. Switch остаётся отдельным понятным действием.
- Действие связано с захваченными Territory UUID + import UUID; текст служит
  только подписью. Совпадающие имена различаются как в базовом MD.
- Заголовок: `Удалить трек?`.
- Текст: `«{название}» будет удалён из Bee Search вместе с сохранёнными координатами. Исходный файл в другой папке телефона не затрагивается.`
- `Отмена`, Back и закрытие подтверждения ничего не удаляют.
- Только `Удалить` начинает операцию, повторная команда блокируется.
  Диалог закрывается; строка временно недоступна, accessibility сообщает
  `Удаление`. До durable результата исчезновение строки не имитируется.
- Длинное имя/сообщение естественно переносятся; при нехватке высоты тело диалога
  прокручивается, кнопки доступны, минимальная область касания48dp. При font1.7
  кнопки расположены вертикально. Ни уменьшения fontScale, ни ellipsis.
- После подтверждённого durable удаления строка и её overlay исчезают, остальные
  строки/overlays сохраняются. Пустой список использует прежнее empty state.
- Ошибка до durable удаления: строка остаётся, `Не удалось удалить трек` /
  `Повторить`; Повторить вновь открывает подтверждение для того же UUID.
- После durable удаления, но при отложенной очистке файлов, не показывать ложный
  возврат удалённой строки: cleanup продолжается по durable deletion journal.
  Это внутренний результат, не успешное удаление всех байтов до fsync cleanup.
- Смена Territory закрывает меню/диалог; устаревший callback не удаляет иной UUID.
  Подтверждённая операция сохраняет исходную Territory и завершается безопасно.

Production UI/backend deletion is implemented against this contract. The durable
result is keyed by exact Territory UUID + import UUID. A feature-local Room
deletion journal/tombstone survives cleanup and blocks old request/import replay.
Stage1/H05 OPEN. Backup/Restore and My points are outside this slice.
